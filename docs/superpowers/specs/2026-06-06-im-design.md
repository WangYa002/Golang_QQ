# Golang_QQ 即时通讯项目设计文档

## 概述

个人社交即时通讯应用，类似微信的聊天体验。单体架构，Go 后端 + React 前端，WebSocket 实时通信，MongoDB 存储。

## 技术栈

**后端 (Go)**
- Gin — HTTP 框架
- gorilla/websocket — WebSocket
- mongo-driver — MongoDB 驱动
- bcrypt — 密码加密
- golang-jwt — 会话 Token

**前端 (React)**
- Vite + TypeScript — 构建工具
- React Router — 路由
- Zustand — 状态管理
- TailwindCSS — 样式
- 原生 WebSocket API — 实时通信

**基础设施**
- MongoDB 6+ — 数据存储
- 本地开发环境

## 架构

单体架构，一个 Go 服务处理所有逻辑：

```
React Frontend (Vite + TypeScript)
    ↕ WebSocket + REST API
Go Backend (Gin + WebSocket Hub)
    ↕ MongoDB Driver
MongoDB (users · messages · conversations · groups)
```

## 数据模型

### users
| 字段 | 类型 | 说明 |
|------|------|------|
| _id | ObjectId | 主键 |
| username | string | 用户名，唯一索引 |
| password | string | bcrypt 加密 |
| nickname | string | 昵称 |
| avatar | string | 头像 URL |
| status | string | online / offline / away |
| created_at | datetime | 注册时间 |
| updated_at | datetime | 更新时间 |

索引: `{ username: 1 }` (unique)

### conversations

|------|------|------|
| _id | ObjectId | 主键 |
| type | string | "private" / "group" |
| members | []ObjectId | 参与者用户ID |
| group_id | ObjectId|null | 群聊关联 group |
| last_message | embedded | 最后消息摘要 |
| created_at | datetime | |
| updated_at | datetime | |

索引: `{ members: 1 }`

### messages
| 字段 | 类型 | 说明 |

### groups

| members | []object | [{user_id, role, joined_at}] |

| created_at | datetime | |
| updated_at | datetime | |

## REST API

### 认证
- `POST /api/auth/register` — 注册
- `POST /api/auth/login` — 登录，返回 JWT token

### 用户
- `GET /api/users/me` — 当前用户信息
- `PUT /api/users/me` — 更新个人信息
- `GET /api/users/search?q=` — 搜索用户

### 会话与消息
- `GET /api/conversations` — 会话列表
- `POST /api/conversations` — 创建单聊会话
- `GET /api/conversations/:id/messages` — 历史消息(分页)

### 群组
- `POST /api/groups` — 创建群组
- `GET /api/groups/:id` — 群组详情
- `POST /api/groups/:id/members` — 邀请入群
- `DELETE /api/groups/:id/members/:uid` — 移出群/退群

### 文件
- `POST /api/upload` — 文件上传

## WebSocket 协议

连接: `ws://localhost:8080/ws?token=JWT_TOKEN`

所有消息格式: `{ "type": string, "data": object }`

### 客户端 → 服务器
| type | data | 说明 |
|------|------|------|
| chat | {conversation_id, type, content} | 发送消息 |
| typing | {conversation_id} | 正在输入 |
| read | {conversation_id, message_id} | 标记已读 |
| heartbeat | {} | 心跳保活 |

### 服务器 → 客户端
| type | data | 说明 |
|------|------|------|
| new_message | {message对象} | 新消息通知 |
| typing | {conversation_id, user_id, username} | 对方输入中 |
| read_receipt | {conversation_id, message_id, user_id} | 已读回执 |
| user_online | {user_id} | 用户上线 |
| user_offline | {user_id} | 用户下线 |
| heartbeat | {} | 心跳响应 |

## 消息流转

1. 用户A 通过 WebSocket 发送 chat 消息
2. 服务器 Hub 接收，写入 MongoDB
3. Hub 广播 new_message 给会话中所有在线用户
4. 离线用户下次上线时通过 REST API 拉取未读消息

## 前端界面

三栏布局，暗色主题：
- **左栏 (64px)**：导航栏 — 头像、聊天、联系人、文件、设置
- **中栏 (260px)**：会话列表 — 搜索框、会话项(头像/名称/最后消息/时间/未读数)
- **右栏 (自适应)**：聊天区 — 头部(名称/在线状态)、消息列表、输入区(附件/输入框/发送)

核心页面：登录注册、联系人列表、群聊管理、文件图片发送

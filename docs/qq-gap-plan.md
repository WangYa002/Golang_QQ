## 一、差距对比（当前 vs 参考图）

| 区域 | 参考图（QQ） | 当前前端 | 差距 |
|---|---|---|---|

## 二、补齐计划（按优先级）

1. **右侧群信息面板**（核心，最直观缺口）
   - 新建 `GroupInfoPanel.tsx`：常驻聊天区右侧（群聊时显示），含
     - 「群公告」卡片（可折叠，读 `groupDetails[groupId].announcement`）。
     - 「群聊成员 {count}」列表（读 `getGroupMembers`），每项：圆形头像 + 昵称 + 角色徽章（群主/管理员），右上角搜索图标。
   - `ChatArea` 群聊时渲染该面板，替换原“点击才弹出的群成员侧栏”。
2. **聊天头部增强**
   - 成员数下拉 chip（显示 `{成员数}` + chevron，点击切换右侧面板）。
   - 加“投屏”按钮（`ScreenShareIcon`）。
3. **输入区**
   - 发送按钮改为 QQ 式：蓝色圆角 + “发送”文字 + 纸飞机图标。
   - 工具条补“截图/语音”占位图标（可后续接功能）。
4. （可选，暂不实现死按钮）左栏/顶栏的天气、收藏、菜单等装饰图标。

Golang_QQ 即时通讯 — 数据模型

MongoDB Collections 设计

users — 用户表

Collection: users
_id: ObjectId // 主键
username: string // 用户名，唯一
password: string // bcrypt 加密
nickname: string // 昵称
avatar: string // 头像 URL
status: string // online / offline / away
created_at: datetime // 注册时间
updated_at: datetime // 更新时间

conversations — 会话表

Collection: conversations
_id: ObjectId // 主键
type: string // "private" 单聊 / "group" 群聊
members: []ObjectId // 参与者用户ID列表
group_id: ObjectId|null // 群聊时关联 group
last_message: embedded // 最后一条消息摘要
created_at: datetime
updated_at: datetime

messages — 消息表

Collection: messages
_id: ObjectId // 主键
conversation_id: ObjectId // 所属会话
sender_id: ObjectId // 发送者
type: string // "text" / "image" / "file" / "system"
content: string // 文本内容或文件URL
metadata: object|null // 富媒体附加信息 (尺寸/文件名等)
read_by: []ObjectId // 已读用户列表
created_at: datetime

groups — 群组表

Collection: groups
_id: ObjectId // 主键
name: string // 群名
avatar: string // 群头像
owner_id: ObjectId // 群主
members: []object // [{user_id, role, joined_at}]
max_members: int // 最大人数，默认 500
created_at: datetime
updated_at: datetime

索引策略

users: { username: 1 } (unique)
messages: { conversation_id: 1, created_at: -1 } (消息列表查询)
conversations: { members: 1 } (用户会话列表)
groups: { "members.user_id": 1 } (用户所在群)

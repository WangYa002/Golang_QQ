Golang_QQ 即时通讯 — API & WebSocket 协议设计

RESTful API + WebSocket 消息协议

REST API 端点

API Routes
POST /api/auth/register // 注册
POST /api/auth/login // 登录，返回 JWT token
GET /api/users/me // 获取当前用户信息
PUT /api/users/me // 更新个人信息
GET /api/users/search?q= // 搜索用户
GET /api/conversations // 会话列表
POST /api/conversations // 创建单聊会话
GET /api/conversations/:id/messages // 历史消息(分页)
POST /api/groups // 创建群组
GET /api/groups/:id // 群组详情
POST /api/groups/:id/members // 邀请入群
DELETE /api/groups/:id/members/:uid // 移出群/退群
POST /api/upload // 文件上传

WebSocket 协议

WS Endpoint: ws://localhost:8080/ws?token=JWT_TOKEN
// 所有消息格式: JSON { type, data }
// 客户端 → 服务器
chat → 发送消息 {conversation_id, type, content}
typing → 正在输入 {conversation_id}
read → 标记已读 {conversation_id, message_id}
heartbeat → 心跳保活 {}
// 服务器 → 客户端
new_message → 新消息通知 {message对象}
typing → 对方输入中 {conversation_id, user_id, username}
read_receipt → 已读回执 {conversation_id, message_id, user_id}
user_online → 用户上线 {user_id}
user_offline → 用户下线 {user_id}
heartbeat → 心跳响应 {}

消息流转

Message Flow
用户A 发送 chat 消息 → WebSocket Hub → MongoDB
↓ 写入后
WebSocket Hub 广播 new_message → 用户B (在线) | 用户C (离线，下次上线拉取)
